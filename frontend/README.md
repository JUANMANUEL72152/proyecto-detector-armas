# Frontend React (opcional)

La guía principal del proyecto está en el **[README de la raíz](../README.md)**.

- **`http://localhost:5000`** — servidor Flask en vivo (interfaz HTML incluida). Es el modo habitual si solo ejecutas el backend.

- **`http://localhost:3000`** — solo existe si ejecutas desde esta carpeta:

```bash
npm install
npm start
```
